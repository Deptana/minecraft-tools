# Report a DEPTANA bug / Сообщить об ошибке

Use Russian or English. One reproducible problem per issue makes it easier to investigate.

## What to include

- Tool URL without private query parameters.
- Minecraft edition, exact version and relevant mod loader or server software.
- Browser and operating system.
- Steps to reproduce, expected result and actual result.
- For generated commands: the command, how you ran it and the exact game error.
- For calculations: the inputs and the result you expected, with the reason or source.

Screenshots help when they show the relevant controls and result. Redact names, private server addresses and account details first. Do not upload an entire world or private log to a public issue. A small redacted excerpt is usually enough to start.

Security reports that contain an exploit or private information should not be posted publicly. This repository does not offer a private security-reporting channel yet. Do not test systems you do not own or have permission to test.

## Что написать

Укажи страницу инструмента, точную версию игры, браузер и шаги, после которых появилась ошибка. Опиши ожидаемый и полученный результат. Если не работает команда, добавь её текст и сообщение из игры.

Для расчёта нужны исходные параметры и объяснение, почему результат должен быть другим. На снимке должны быть видны нужные настройки. Перед отправкой скрой личные данные, адреса приватных серверов и сведения об аккаунте. Полный лог или мир публично выкладывать не нужно.

У этого репозитория пока нет закрытого канала для сообщений об уязвимостях. Не публикуй здесь эксплойты и секреты. Проверяй только свои системы или те, на тестирование которых получено разрешение.
