# DEPTANA — инструменты для Minecraft Java

[Открыть сайт](https://deptana.ru/ru?utm_source=github&utm_medium=referral&utm_campaign=project_readme_ru) · [English guide](README.md)

На DEPTANA можно собрать команду для своей версии игры, рассчитать порядок зачарований на наковальне и посмотреть замеры из отчёта о лагах. Инструменты бесплатные, регистрация на сайте не нужна.

Здесь лежат инструкции и сообщения об ошибках. Исходный код сайта в этот репозиторий не входит.

## Как получить команду

1. Открой генератор и выбери задачу: например, ночное зрение или предмет с чарами.
2. Укажи свою версию Minecraft Java. Если её нет в списке, совместимость команды с ней не заявлена. Bedrock использует другой синтаксис.
3. Настрой параметры и скопируй результат.
4. В своём мире включи команды, открой чат клавишей T и вставь команду. На сервере понадобятся права на её выполнение.

Если игра выдаёт ошибку, открой «Команда не сработала?» под результатом. Проверь версию, права и длину команды: это разные причины сбоя.

## Как проверить лаги

Зайди в мир Java Edition и нажми F3 + L. Пока идёт запись, повтори действие, при котором игра тормозит. Примерно через 10 секунд ZIP появится в папке игрового профиля `debug/profiling`. На некоторых клавиатурах нужна ещё клавиша Fn.

Открой ZIP в диагностике лагов. Файл разбирается в браузере. Инструмент показывает доступные замеры и подсказывает, что проверить. Большая доля времени в отчёте ещё не доказывает причину тормозов. Отсутствующий замер не означает нулевое значение. Поменяй один параметр и повтори запись в той же сцене.

Для вылета игры нужен другой файл: отчёт из `crash-reports` или `logs/latest.log`. Открой его в диагностике вылетов. По одному Exit Code обычно нельзя установить причину.

## Если что-то не работает

Перед публикацией убери из снимков и фрагментов логов личные данные. Не прикладывай целиком приватные логи, токены или данные аккаунта. [Что указать в сообщении](CONTRIBUTING.md).
